# Adidas Sales Dashboard

A Power BI dashboard project for exploring Adidas sales data and presenting business insights through interactive visualizations.

## Project File

- `adidas dashboard.pbix` — Open this Power BI Desktop file to explore the report and its visuals.

## Getting Started

1. Clone or download this repository.
2. Install [Microsoft Power BI Desktop](https://powerbi.microsoft.com/desktop/).
3. Open `adidas dashboard.pbix` in Power BI Desktop.
4. If the report uses an external data source, configure the required source and refresh the data when prompted.

## Project Overview

This project is intended to support visual exploration of Adidas sales data. Review the report pages, filters, and charts in Power BI to understand the specific metrics and findings included in the dashboard.

## Tools

- Microsoft Power BI Desktop
- Power BI report file (.pbix)

## Notes

The repository currently includes the Power BI report file. Dataset details, data preparation steps, and specific business findings should be added after reviewing the report's contents and data source.
